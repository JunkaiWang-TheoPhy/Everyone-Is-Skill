# Everyone Is a Skill repository guidance

## Product boundary

This repository reconstructs bounded, evidence-grounded methods and practices. It does not clone people, infer private mental states, or use a name as a substitute for evidence.

## Source and attribution rules

- Resolve identity before collecting a corpus.
- Keep raw copyrighted and private materials outside committed profile packages.
- Every person-specific claim must link to source identifiers and state attribution strength plus coauthor risk.
- Preserve counterevidence, historical change, minority views, and abstentions.
- Never relicense imported content or third-party code through the repository's Apache-2.0 license.

## Development

- Add behavior or bug fixes through focused tests first.
- Keep core validation dependency-free unless a new dependency is explicitly approved.
- Validate JSON, Skills, plugin manifests, profile examples, Markdown links, and legal notices before release.
- Treat synthetic eval files as specifications until an execution result is recorded separately.

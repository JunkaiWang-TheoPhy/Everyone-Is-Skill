# Code of Conduct

Everyone-Is-Skill is a provenance-first project. We expect contributors to
make claims that can be checked, attribute upstream work accurately, and keep
the discussion focused on the artifact rather than the person.

## Expected behavior

- Be respectful and direct.
- Attribute upstream sources accurately.
- Keep disagreements focused on evidence, scope, and implementation.
- Protect private data, secrets, and unpublished material.
- Distinguish inspiration from redistribution.

## Unacceptable behavior

- harassment, intimidation, or hate speech
- doxxing or threats
- source laundering or false attribution
- deliberate license misrepresentation
- posting secrets, personal data, or unredacted sensitive material
- repeated disruption after a maintainer asks for a correction

## Enforcement

Maintainers may:

- ask for a correction or clarification
- remove inaccurate or harmful content
- reject contributions that violate attribution or licensing rules
- restrict participation after repeated or serious violations

## Reporting

Use the repository's private security or maintainer channel if available. If no
private channel exists, open a minimal issue and avoid including sensitive
details.

## Scope

This policy applies to issues, pull requests, reviews, discussions, and any
other contribution channel used for the project.

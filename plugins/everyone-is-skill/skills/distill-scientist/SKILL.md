# Distill Scientist

Target the repeatable research method, not biography and not field-generic praise.

1. Resolve identity and time window before inferring style.
2. Separate source facts, observed patterns, supported methods, and counterevidence.
3. Extract the method kernel that recurs across papers, talks, notes, or interviews.
4. Write outputs that stay auditable: `SKILL.md`, claims, provenance, and eval stubs.

Read [evidence policy](../../references/evidence-policy.md), [profile contract](../../references/profile-contract.md), [evaluation protocol](../../references/evaluation.md), [claim schema](../../schemas/claim.schema.json), and [profile schema](../../schemas/profile.schema.json).

Reject claims that are only about fame, topic area, or a single coauthored result without attribution support.

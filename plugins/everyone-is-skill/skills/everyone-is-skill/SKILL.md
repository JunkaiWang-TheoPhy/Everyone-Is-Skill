# Everyone Is a Skill

Route first, then execute one focused skill.

- Use `distill-scientist` for scientists or research-method reconstruction.
- Use `distill-person` for creators, operators, or other individuals.
- Use `distill-team` for labs, schools, companies, or named collaborations.
- Use `distill-content` for books, talks, interviews, courses, or mixed corpora.
- Use `evaluate-profile` before release or after material edits.
- Use `update-profile` when a profile already exists and new evidence changes it.
- Use `import-profile` when adapting an external repo, profile, or skill package.

Before writing claims, read [profile contract](../../references/profile-contract.md), [evidence policy](../../references/evidence-policy.md), and [profile schema](../../schemas/profile.schema.json).

Do not impersonate the subject, infer private mental states, or turn weak evidence into person-specific certainty.

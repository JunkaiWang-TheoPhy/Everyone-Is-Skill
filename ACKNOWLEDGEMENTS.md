# Acknowledgements

Everyone-Is-Skill is built on ideas proved by other projects first.

We thank the maintainers and contributors of:

- `AITCX08/Distill-Everything` for showing a practical local pipeline from raw
  media to reusable skill artifacts.
- `Nouischen/anything2skill` for treating external knowledge as something that
  can be filtered, fused, and activated with discipline.
- `QuantumBFS/sci-brain` for the scientist-oriented workspace model and the
  emphasis on knowledge collection around real research workflows.
- `Jingqi-Xu/research-taste-distillation` for a clear focus on research taste,
  philosophy, and critique rather than surface imitation.
- `alchaincyf/nuwa-skill` for demonstrating public-figure distillation as a
  runnable skill format.
- `titanwings/distilly` for the two-layer view of capability and persona.
- `person-distillation-foundations/person-distillation-foundations.github.io`
  for naming the broader person-distillation problem space.
- `InternScience/Virtual-Scientists` for multi-agent scientific workflow and
  ecosystem thinking.
- `K-Dense-AI/scientific-agents` for expert-thinking profiles that teach AI
  agents how to reason like domain specialists.
- `K-Dense-AI/scientific-agent-skills` for the skill-library format and the
  scientific adapter catalog.
- `tsinghua-fib-lab/OmniScientist-V2` for provenance, workflow, and
  co-evolving scientist ecosystem ideas.

If you maintain one of these repositories, thank you for making the design
space legible before this project tried to formalize it.

# Method

Start from the smallest exact structure that keeps the invariant visible, then widen the formalism only after the control calculation survives. Treat geometry, topology, duality, and exact algebra as different entry points into the same problem rather than as interchangeable rhetoric.

When a route splits, preserve the minority branch and document why the split matters. The collective method is a routing map across subfields, not a promise that every problem has one universal language.

Treat disagreement as data instead of noise: if two branches make different invariants or limits visible, keep both until the failure mode is explicit.

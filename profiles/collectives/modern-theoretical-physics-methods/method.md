# Method profile

## Route by obstruction

1. If an assumed symmetry may be wrong or incomplete, use the Yang branch: define it operationally and derive decisive constraints or tests.
2. If the target is a global geometric object and formal existence is not enough, use the Yau branch: identify the controlling equation and the estimate, compactness, and regularity gates.
3. If robustness or phase structure is hidden, compare the Kitaev minimal-model branch with the Wen entanglement/classification branch instead of merging them.
4. If one description is strongly coupled or opaque, compare the Seiberg exact-duality branch, the Maldacena controlled holographic-limit branch, and the Nekrasov localization branch by their different assumptions.
5. If the representation itself creates complexity, compare the Arkani-Hamed on-shell/positive-geometry branch with the Siegel manifest-covariance/superspace branch.

## Preserve disagreement and minority strategies

Do not vote these branches into one answer. Record which primitive each branch changes, what evidence it accepts, and what would falsify the transfer. Keep a minority route when it exposes a different obstruction, even if another route is easier to compute.

## Output contract

Report the selected role, historical context, assumptions, invariant or controlling equation, comparison branch, disagreement, limiting case, and evidence boundary. This collection is a router among profiles, not a fictional consensus or collaboration.

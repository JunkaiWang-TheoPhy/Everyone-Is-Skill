# Counterevidence

Not every successful physics problem rewards the same first move. Some arguments need local PDE control before any exact structure is visible, while others only become tractable after a duality frame change or a representation shift.

This profile should therefore be read as a comparative map with explicit failure modes. If a candidate transfer cannot identify a conserved quantity, a protected observable, or a reliable limit, the method should stop rather than pretend that analogy is enough.

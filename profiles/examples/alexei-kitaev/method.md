        # Method profile

        ## Method kernel

        Start from the smallest model in which the target behavior is enforced by structure rather than recovered through repeated tuning.

        ## Selection criteria

        - Prefer exact or nearly exact reference points.
- Keep the solvable point separate from the surrounding phase.
- Test perturbations, disorder, locality, and realization before calling a mechanism robust.

        ## Output contract

        Report the target property, minimal degrees of freedom, protection mechanism, solvable reference point, perturbation window, natural realization, and the boundary between robust and fine-tuned claims.

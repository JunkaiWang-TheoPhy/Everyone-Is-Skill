# Counterevidence

- An exactly solvable Hamiltonian can require specially chosen couplings. Exact solvability and absence of fine-tuning are different claims.
- A phase may be robust although the reference point is not. Test the phase, not only the solvable point.
- A minimal model may omit the ingredients needed for a material or device realization.
- Several sources are coauthored. Attribute only patterns that recur across source types or are stated directly by Kitaev.
